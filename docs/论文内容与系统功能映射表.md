# 论文内容与系统功能映射表（PV-Risk）

> 本表说明论文《光伏上市公司财务困境预警研究与应用——基于 Firth Logit 与 LightGBM 的比较》
> 每个章节、表格与图片在 PV-Risk 系统中的展示位置与实现方式。
> 实现方式分三类：**【真实计算】** 系统按论文公式实时计算；**【论文实证结果】** 使用论文已公布数据静态/交互展示，明确标注；**【不可实现】** 当前无原始数据或模型文件，仅展示论文结果、不伪装为实时运行。

### 3.3 Firth Logit 评分卡（论文第 7 章 / 表 7-2）
| 步骤 | 论文要求 | 实现方式 | 配置来源 |
|---|---|---|---|
| 第一步 缩尾 | 按 P1/P99 截断 | 【真实计算】core/preprocessing.py | model_parameters.scorecard_params |
| 第二步 标准化 | z=(x−mean)/std（缩尾后参数） | 【真实计算】 | 同上 |
| 第三步 logit | −1.941 + Σ(β·z) | 【真实计算】core/firth_scoring.py | 同上 |
| 第四步 分值 | 100/(1+exp(−logit)) | 【真实计算】 | 同上 |
| 第五步 等级 | A<11.52 / B / C / D>33.24 | 【真实计算】阈值不修改 | risk_levels.json |
| 风险来源 | 单项贡献=系数×z，取正向最大三项 | 【真实计算】core/risk_attribution.py | model_parameters.firth_logit |

## 六、使用边界总说明（论文第三节要求）

**A. 可真实计算**：八项指标、缺失/异常检查、缩尾、Z-score、Firth 评分、风险等级、贡献分解、海源复材复算、用户输入/上传数据评分。

**B. 仅展示论文已公布结果**（标注"论文实证结果"）：描述性统计、模型训练/测试结果、LightGBM 各版本比较、ROC/PR 曲线、SHAP、滚动外推、Bootstrap、概率校准、预警名单、各项稳健性检验。

**C. 暂不实现**（不伪装为实时运行）：基于原始 765 观测重训全部模型、重生成真实 LightGBM 预测、对任意企业运行 LightGBM、无模型文件的真实 SHAP 计算、自动查询全部 A 股历史财报。
